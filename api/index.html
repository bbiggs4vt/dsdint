WebSocket · flat JSON

dsd-server API

FM-demodulate SDR IQ and decode digital voice over one WebSocket. Stream float32 IQ as binary frames, drive the pipeline with JSON control frames, receive started / error / event frames and tagged PCM audio.

AsyncAPI models this interface the way it actually behaves — one channel, messages flowing both ways — rather than as request/response.

Operations are written from the client's point of view: publish is what the client sends, subscribe is what it receives. The full machine-readable spec is below; paste it into AsyncAPI Studio for the same interactive treatment as the OpenAPI tab.

Channel / — the one session

▲ publish · client → server

Control the pipeline (text) and feed it samples (binary).

  • startbuild the demod + decode pipeline
  • set_gainlive discriminator gain
  • set_freq_offsetlive NCO retune (resets AFC)
  • stoptear the pipeline down
  • IQLE float32 I/Q, binary

▼ subscribe · server → client

Status and decoder activity (text) plus decoded audio (binary).

  • startedpipeline is up
  • errora message was rejected
  • eventdecoder activity, 13 flat fields
  • audio0x01 tag + s16 PCM, binary

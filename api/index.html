dsd-server API

FM-demodulate SDR IQ and decode digital voice over one WebSocket. Stream float32 IQ as binary frames, drive the pipeline with JSON control frames, receive started / error / event frames and tagged PCM audio.

A bidirectional, message-driven protocol — modeled with AsyncAPI, the format built for it.

Operations are written from the client's point of view: publish is what the client sends, subscribe is what it receives. Expand any message for its schema and examples; the full machine-readable spec is at the bottom.
